# Apex V3 — research

Oberoende beslutsunderlag för Apex V3. Repositorynamnet är `apex-v3-reserach`.

## Status 2026-10-14

**Pass 1: källstudien levererad.** Plattformskarta, evidensregister, kritisk prövning och verifieringsunderlag finns nedan. Detta betyder inte att Apex V2 eller V3 har körtestats. Den detaljerade officiella Projects-sidan kunde inte hämtas; dess luckor är uttryckligen avgränsade.

| Underlag | Innehåll |
|---|---|
| [Plattformskarta](research/01-projects-architecture.md) | Slutsatser, produktgränser, informationsflöden och konsekvenser för V3 |
| [Källregister](research/01-sources.md) | Primärkällor, lästa avsnitt, incidentrapporter och hämtningsbegränsningar |
| [Evidensmatris](research/01-evidence.csv) | Påståenden med källor, tillämpningsområde och verifieringsbehov |
| [Verifiering och överlämning](research/01-validation-and-handoff.md) | Föreslagna runtimeprov, motargument och frågor till V2-granskningen |
| [Metod](research/01-method.md) | Vilka skills som tillämpats och hur metoderna avgränsats |

Pass 2 behandlar minnes-, kontext- och instruktionsarkitektur samt automationsalternativ. Pass 3 behandlar kvalitet, effektivitet och slutlig syntes. De är **inte genomförda** i denna leverans.

## Användning

Läs plattformskartan först. Jämför sedan dess kontrollpunkter med den separata V2-granskningen och den oberoende red-team-rapporten. Avgör arkitekturen utifrån belägg, inte genom majoritetsomröstning mellan AI-rapporter.

Detta är ett researcharkiv, inte en ny backend. Kopiera inte hela arkivet till `CLAUDE.md`, ett automatiskt minnesindex eller ett alltid laddat skillpaket. Inga V2-filer eller driftinställningar har ändrats av detta researchspår.

Repositoryt är publikt. Privata transcripts, skärmbilder, hemligheter, kontodata och lokala användarsökvägar ingår inte. Tekniska observationer från projektinställningarna återges endast i minimerad form. Den ursprungliga `connection-test.md` bevaras.
